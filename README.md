# Iris Flower Classification

## Objective

The objective of this project is to build a machine learning model that can classify iris flowers into three species: Setosa, Versicolor, and Virginica based on their flower measurements such as sepal length, sepal width, petal length, and petal width.

## Steps Performed

The dataset was first loaded and analyzed using Pandas. Basic data preprocessing and dataset inspection were performed to understand the structure of the data. The features and target variables were separated, and the dataset was divided into training and testing sets. A machine learning classification model was then trained using Scikit-learn. Finally, predictions were made and the model performance was evaluated using accuracy metrics.

## Tools and Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Outcome

The machine learning model successfully classified iris flower species with high accuracy. This project helped in understanding the basics of supervised machine learning, classification algorithms, data preprocessing, and model evaluation.
